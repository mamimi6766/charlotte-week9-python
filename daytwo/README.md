# Part C — Reflection

A list of dictionaries is useful for sensor observations because each dictionary can represent one observation, with clear labels such as well ID, field, time, and pressure. The list keeps observations in their original order, so earlier and later readings can be selected by index or slice. It also preserves repeated observations. For example, WELL-07 may appear several times because it was measured more than once; each reading remains a separate record. A set of well IDs can be made separately to count distinct wells, but using a set as the observation data would lose repeated records. Keeping each observation as its own dictionary makes it possible to count readings per well, calculate pressure summaries across all records, and review the original measurements. This structure is readable and useful for small in-memory engineering datasets.
